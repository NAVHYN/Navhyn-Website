# NAVHYN multi-service website starter

## Included
- `index.html` — main page and overview of all service lines
- `services/eor.html` — Employer of Record / EOR coordination in India
- `services/managed-office.html` — managed office services in India
- `services/hr-talent.html` — HR and talent acquisition in India
- `services/accounting-canada.html` — accounting support for Canadian SMBs
- `contact.html` — enquiry form template
- `assets/css/styles.css` — shared design system and responsive styles
- `assets/js/main.js` — mobile menu and demo form interaction
- `robots.txt` and `sitemap.xml` — starter SEO files

## Important before publishing
1. This is a static HTML/CSS/JS starter, not a CMS. Upload the folder structure as-is to your host, or adapt paths if the site is deployed in a subdirectory.
2. The contact form is not connected to email or a CRM. Connect it to a secure form handler (or your chosen CRM) and add spam protection, privacy consent, and a privacy policy before accepting enquiries.
3. Confirm that `https://www.navhyn.ca/Logo_Modified.svg` is the correct live logo path. If your host uses a different path, update the image `src` in the header and footer.
4. Review all service claims, especially EOR/legal-employer wording and accounting services. Confirm the actual provider, deliverables, geographic scope, professional qualifications and any applicable regulatory requirements before publishing.
5. Replace canonical URLs if your final page URLs differ. Add a privacy policy and any required cookie/consent disclosures.
6. Submit `https://www.navhyn.ca/sitemap.xml` in Google Search Console after the pages are published.

## Where to edit copy
Every page has HTML comments marking the hero, service details, FAQs, and CTA areas. The shared header/footer is repeated in each HTML page; if you change navigation, update it across all pages or use a templating/CMS system to centralize it.

## SEO approach
Each page has its own title, meta description, canonical URL, social metadata and relevant service wording. This creates a sound technical/content foundation, but no code can guarantee a top Google position. Rankings also depend on search intent, competition, useful original content, site performance, links, local relevance and ongoing improvements.
